# Social Media Dashboard

A high-fidelity front-end prototype for a Social Media Dashboard (SMD), built using HTML, Tailwind CSS, and Chart.js.

The dashboard provides a centralized view of multiple social media platforms, allowing users to monitor followers, engagement rates, audience distribution, and platform performance in one place.

## How to Run

You need a modern browser and an internet connection because Tailwind CSS, Chart.js, and Google Fonts are loaded from CDNs.

### Option 1: Open Directly

1. Unzip the project folder.
2. Double-click `index.html`.

### Option 2: Run Using a Local Server

Open the project folder in VS Code and run:

```bash
python -m http.server 8000
